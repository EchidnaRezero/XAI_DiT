# Milestone 1 (M1) Scope, Backend & Invariant Matrix

M1 establishes the pure-PyTorch core (`src/xai_dit/`), headless ComfyUI execution runner, 3 model adapters, and CPU/GPU verification harness required to execute Phase 1–3 L4 experiments cleanly.

---

## 1. Execution Backend & Boundaries
- **Core (`src/xai_dit/core/`)**: Pure PyTorch only (zero `comfy.*` imports).
- **Execution Backend (`src/xai_dit/runners/cli.py`, `src/xai_dit/adapters/`)**: **Headless ComfyUI (`comfy.*`)** for model loading (`fp8_scaled` / `int8_convrot` / `bf16` single-file safetensors), conditioning, and deterministic `euler` sampling on Colab L4+.
- **UI Wrapper (`src/xai_dit/comfyui/nodes.py`)**: Thin ComfyUI custom-node wrapper around `core/` (added after core + CLI E0 pass).
- **Out of Scope for M1**:
  - `ProbeSelect` listwise probe training (deferred to **M3+**; M1 provides `residual_out` tap contract only; M2 runs training-free early-step correlation).
  - Late-step head pruning (`04_verification_mi.md` Paper 2 Sec 4.5 — deferred).
  - Phase 4 A100/H100 full-precision BF16 & `k=64` sweeps (handled by the same CLI with precision/shard flags once M1 passes L4).

---

## 2. M1 Deliverables
1. **Adapters (`src/xai_dit/adapters/{base,anima,moss_image,krea2}.py`)**:
   - `TokenMap` (exact `token_ids`, `occurrence_idx`, half-open `S/R/P` spans, strict token-alignment checker).
   - Disambiguated `capture` fields (`q, k, v, probs, attn_pre_proj, attn_out, gate_logits, gate_value, residual_out`).
   - Full `intervene` hooks (`kv_patch`, `logit_knockout`, `logit_scale`, `attn_override`, `two_pass_sink_mask`, `span_query_mask`, `pre_dit_span_swap`, `gate_override`, `per_head_token_ablation`, `concept_stream`, `true_block_bypass`).
   - Fixed CFG batching policy + `cond_or_uncond` chunk-to-sample mapping + sigma-derived step index from `transformer_options["sigmas"]`.
2. **Core (`src/xai_dit/core/`)**:
   - `session.py` (query-chunked + OOM key-chunked `logsumexp` softmax, streaming `RunningMap`, fixed-policy hook manager).
   - `heatmap.py` (E1-1/E1-2/E1-3), `layer_selection.py` (E2-1/E2-2 using `wo(x)` module call), `patching.py` (E3-0..E3-4 + offline BF16 cond cache), `verification.py` (E4-1..E4-5), `profiling.py` (VRAM/RSS/`sec_per_forward`).
3. **Prompt Manifests (`experiments/design/manifest_{anima,moss_image,krea2,shared_rel}.json`)**:
   - Disjoint `calib` / `rank` / `eval` splits (`k >= 16` per model + ~20 reversed-pair relation prompts), `localizable` flags, length-matched `neutral_sub`, and `vqa_question`.
4. **Tests (`tests/`)**:
   - CPU unit tests covering all M1-scoped invariants below.

## 3. M1 E0 Verification Invariant Matrix (CPU Unit Tests)

| Domain | Invariant (M1 Pass/Fail) | Spec Ref |
